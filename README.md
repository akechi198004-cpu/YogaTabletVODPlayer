## 当前主要功能

- 顶部导航：首页、分类、榜单、更新、收藏，以及搜索。
- 首页精选为多作品大图轮播：高200dp，最多8部，左右切换、确认进入详情，聚焦或离开页面时暂停自动轮播。
- 电视海报墙固定六列，2:3纵向海报、两行片名；首页压缩精选和留白，让首屏容纳完整海报行。
- 分类支持类型、地区、年份、排序及分页，筛选行可用遥控器切换。
- 榜单是带排名角标的海报网格；更新页是海报网格，每页24条。
- 收藏和历史均进入作品详情。详情提供上次剧集的继续播放及完整选集；选集在电视上每行六个。
- 播放器解析实际线路，并发小样本探测优选线路；保留手动切线、失败重试/备用线路、快进快退、倍速和下一集。
- 同一集切线或兼容代理重试保留进度、暂停状态和倍速；全部线路失败后的手动重试重新解析地址。进入后台暂停，后台解析完成不会自动起播。
- 播放器线路按钮显示简短源名（如 `svipplay(1)`、`ryplay14`）；同一集重名源按出现顺序编号，原线路名保留在无障碍描述中。详情页只有线路编号和剧集，没有源地址，保持原线路名。仅改显示，不改变测速、排序和选线逻辑。
- 电视焦点导航：收藏/历史标签按↓进入第一条记录，记录之间逐条移动，首条↑回标签、末条↓停留；从详情返回恢复原作品焦点和滚动位置，收藏/历史分别记忆。分类翻页后聚焦新页首张海报并回到结果顶部；海报网格左右边缘停留、末行不足时落到最近有效项；结果滚动容器不再抢占焦点。
- 播放进度定时保存（15秒间隔），暂停、切线、换集及退出时补存；最近10条搜索词在本地保存并支持清空。
- 搜索页提供“手机输入”：电视在弹窗内显示本地二维码和短 URL，手机在**同一局域网**浏览器输入关键词并提交，电视填入原搜索框并执行现有搜索。服务只在弹窗期间运行，使用 6 位临时路径码、固定短端口（8899/8787/9090）和一次性会话；手机端不展示结果、不提供选片或遥控功能。
- 手机输入页为页内异步提交：失败时保留已输入文字、显示具体原因并提供“重试”，只有电视明确返回成功才显示“已发送到电视”。若网络中断导致无法确认，会提示先查看电视是否已开始搜索；会话已提交或过期时提示回电视重新打开，不提供盲目重发。请求总时限 8 秒，关闭弹窗会立即关闭监听端口和已建立连接，半途请求不会触发搜索。
- 列表/详情资料与海报具备内存及磁盘缓存、后台刷新和离线展示。**没有视频文件下载缓存**，播放直链不落盘。
