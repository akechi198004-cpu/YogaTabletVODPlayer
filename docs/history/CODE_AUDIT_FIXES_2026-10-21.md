# HM影视代码审计修复记录

基于 [CODE_AUDIT_2026-10-21.md](CODE_AUDIT_2026-10-21.md) 完成了一轮源码修复。未安装模拟器、未连接电视安装 APK，也未下载依赖。

## 已修改

- **A01、A14、A19、A23、A25：播放链路。** HLS 代理流显式声明 HLS MIME；代理绑定 `127.0.0.1`、限制请求头长度、超时和并发；保留上游状态码并按重定向后的 URL 重写播放列表；线路请求携带解析服务页 Referer；专用快进/快退键直接 seek；错误/无源页面与播放控制层互斥，重试入口可用遥控器确认。
- **A02、A03、A15：遥控器与异步页面。** 榜单、更新、收藏、历史、搜索及详情控件加入焦点支持；页面、搜索、详情、播放请求使用请求编号忽略过期回调；分类请求使用不可变筛选快照；“立即播放”使用当前可播放线路，切线路后恢复焦点。
- **A04、A12：错误与重试。** 删除首页、分类、榜单和更新页伪造的影视数据；失败时显示可重试提示；详情和播放重试会清除旧缓存并重新读取，空详情不再进入长缓存。
- **A05：APK 交付。** 网页不再链接旧 APK，旧 APK、Base64 和源码压缩包已移出公开下载目录并放入 `legacy-downloads-2026-10-21/`。电视工程版本更新为 `2.4.0-tv`、版本号 6、包名 `com.hm.video.letv`、最低 API 23。它与旧版 `com.hm.video` 并行安装，收藏和历史不自动迁移。
- **A06、A07：网络边界。** 移除全局信任任意 TLS 证书和主机名的配置；本地 HLS 转发仅监听回环地址，并限制线程数、排队数、请求头长度和读取超时。
- **A08、A09、A10、A11：续播和播放器状态。** 历史记录按剧集 URL 与集数区分；seekbar 方向键调整会实际 seek；播放器只在当前媒体源首次 READY 时恢复历史位置，不因后续缓冲强制播放或抢焦点；切集先停旧流，页面离开时暂停，并仅在返回时恢复此前正在播放的内容。
- **A13、A20、A21：解析器。** 修复 `.html` 后缀和含点号 Tailwind 类选择器；备用剧集按线路 ID 分组；相对播放地址以播放器服务页 URL 为基准；带下划线的分类按已知分类 slug 解析。
- **A16、A22：内存使用。** 海报响应限制为 5 MiB，按目标尺寸采样并处理内存不足；复用控件会取消旧图片请求，缓存大小和条目数有上限并清理过期项。
- **A17、A18、A24：工程检查和功能。** Media3 不稳定 API 的 lint 错误已修复；Linux 打包脚本改为调用 Gradle 离线构建，避免漏掉 Media3 依赖；搜索新增可聚焦的前后翻页并保留分类条件。
- **网页预览：** 最大化播放器不再重复推进进度；Enter 键阻止浏览器再次触发默认按钮操作；预览明确标注没有真实视频播放，下载按钮改为构建状态提示。
