# HM影视电视界面与播放调整（2026-10-23）

## 实现

- 参考 `upstream/launcher` 的 CalmHome 深色风格：深蓝灰背景、柔和径向渐变、低饱和卡片与浅色焦点边框。未修改或安装启动器。
- 单行品牌/导航/搜索；首页精选横幅与海报墙。电视海报默认固定六列，移除电视端“6列”切换按钮；纵向 2:3 海报，两行片名。
- 分类筛选独立横向滚动，遥控器上下跨筛选行、左右切条件；放大按钮和文字。
- 详情页放大片名、信息和操作按钮；简介可确认展开；选集六列，不足一行用空位保持按钮宽度。
- 历史记录改为打开详情页：提供“继续播放·上次那集”，同时保留全部选集。详情页从播放器返回时刷新续播信息。收藏仍打开详情页。
- 多线路进入播放器时最多三路并发探测，总等待上限约八秒；每次请求限读 128 KiB，HLS 跟随播放清单读取实际片段样本，以样本耗时与数据量排序。只进行小样本探测，不代表解码兼容性或持续带宽保证。
- 测速未通过/超时的线路保留为备用；播放失败后仍尝试兼容代理及其余线路。手动选线保留。换集、重试、退出会取消旧测速，旧结果不能覆盖新播放。
